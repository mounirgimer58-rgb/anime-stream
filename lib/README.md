# Anime Stream — Flutter Android + iOS

مشروع واجهة تطبيق أنمي كامل كبداية، يعمل على Android و iOS باستخدام Flutter.

## المميزات
- صفحة رئيسية داكنة بتصميم حديث.
- صور حقيقية وبيانات أنميات يتم جلبها من Jikan API.
- بحث عن الأنميات.
- قائمة الأكثر شعبية.
- صفحة تفاصيل كاملة لكل أنمي:
  - صورة غلاف كبيرة.
  - الاسم.
  - التقييم.
  - السنة.
  - عدد الحلقات.
  - الحالة.
  - التصنيفات.
  - القصة.
  - معلومات إضافية.
  - قائمة الحلقات.
  - المفضلة.
  - مشاركة.
- صفحات المفضلة والحساب.
- تصميم RTL مناسب للعربية.

## التشغيل
1. ثبّت Flutter.
2. افتح المجلد في Android Studio أو VS Code.
3. نفّذ:
   flutter pub get
4. للتشغيل:
   flutter run
5. لبناء APK:
   flutter build apk --release

ملف APK سيكون عادة في:
build/app/outputs/flutter-apk/app-release.apk

## ملاحظة عن المشاهدة
المشروع يحتوي على واجهة زر "مشاهدة"، لكنه لا يضع روابط بث غير مرخّصة. لإضافة المشاهدة الفعلية، اربط زر الحلقة بمصدر فيديو تملك حق استخدامه.

## مصدر البيانات
البيانات والصور التجريبية يتم طلبها من Jikan API (واجهة عامة لبيانات MyAnimeList). يلزم اتصال بالإنترنت داخل التطبيق.
